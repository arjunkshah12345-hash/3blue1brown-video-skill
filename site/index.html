The essence of the derivative

            

          

          

        

      

      
    
    
    
  
    

  
    
    
    It plans the story before the code.
    Question, discovery, insight, timed 20 / 60 / 20, with the narration written before any Python.
    
    
    It paints in the channel's own colours.
    Blue #58C4DD, green #83C167, yellow, red: hex values taken from 3b1b/manim's default config, each with one meaning.
    
    
    It knows the signature moves.
    Equation morphs, epicycles, linear maps, camera zooms and Riemann sums: seven modules in b3b/, eleven working scenes.
    
    
    It scores and narrates its own films.
    audio.py synthesises a piano score and the sound cues, and the open Kokoro voice speaks the captions. No API keys, and the whole render can run on a free Kaggle box.
    
    
    It stays plain Manim.
    Every scene renders with the stock manim CLI. Nothing is patched, so you can keep editing by hand.
