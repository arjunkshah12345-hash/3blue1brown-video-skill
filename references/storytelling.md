# 3Blue1Brown Storytelling Patterns

## The Question-Answer Loop
- Pose a question that creates curiosity
- Explore step by step to answer it
- Each sub-question leads naturally to the next
- Build toward the main revelation

## Concrete to Abstract
1. Start with a specific example the viewer can visualize
2. Explore that example in detail
3. Notice patterns/generalize
4. Show the abstract form
5. Return to concrete to solidify

## Visual Metaphors
- Use physical analogies (water flow, circles, gears)
- Geometry reveals algebra, algebra clarifies geometry
- Transform between representations to show equivalence
- Make the invisible visible

## Pacing
- Slow down for counterintuitive ideas
- Speed up for obvious connections
- Pause at "aha" moments
- Build tension before reveals

## Narration Style
- Conversational, thinking-aloud
- "Let's think about this..."
- "Notice that..."
- "But wait..."
- Self-aware about complexity
